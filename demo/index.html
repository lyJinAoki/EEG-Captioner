These are the paper's five task families, not five EEG signal categories. This walkthrough uses a single synthetic signal and authored answers to explain the tasks. It does not serve TUEG recordings, original captions, or live model predictions.

01 / The research question

Does the language
reflect the EEG?

A plausible caption is only part of the story. Signal-level questions probe whether a model can compare frequency, location, time and hemispheric activity. EEG-Captioner combines these questions with caption supervision in a unified framework.
