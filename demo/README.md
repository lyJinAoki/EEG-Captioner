# EEG-Captioner demo page

Buildless research project page. Serve this directory using a static HTTP server, or open index.html.

The walkthrough is organized by the five paper task families. One synthesized signal is used throughout; all answers are illustrative authored content. No TUEG waveforms or original captions are distributed through this page. Live model inference is not connected.

Public project page: https://lyJinAoki.github.io/EEG-Captioner/
