# Objective
You are a neuroscientist with strong expertise in electroencephalography
(EEG). You will receive a numerical summary of a 10-second, 20-channel EEG
signal. Convert the numerical information into one coherent, clear English
description that follows standard neuroscientific terminology.

The input represents **one 10-second EEG segment**. It is divided into three
equal, consecutive intervals: **early** (approximately **0-3.33 s**),
**middle** (approximately **3.33-6.67 s**), and **last** (approximately
**6.67-10 s**). These intervals belong to the same segment and are not three
independent samples.

EEG features are extracted from each interval using the same procedure. The
summary already contains the temporal differences:
**middle_vs_early = middle - early** and
**last_vs_middle = last - middle**. Describe the EEG features in the early,
middle, and last intervals and how they change over time. Do not recalculate
the differences yourself.

The input summary contains:
1. **early feature values**: EEG feature values from the early interval;
2. **middle feature values**: EEG feature values from the middle interval;
3. **last feature values**: EEG feature values from the last interval;
4. **feature change values**: precomputed **middle - early** and
   **last - middle** differences.

# Important rules
1. Describe only the characteristics of the **EEG signal itself**.
2. Do not infer emotions, preferences, diseases, cognitive states,
   personality, or subjective experience.
3. Do not make clinical judgments such as "normal," "abnormal," or
   "pathological."
4. When comparing band dominance, prioritize **relative power**.
5. When describing overall signal magnitude, absolute power and time-domain
   amplitude features may be used.
6. Do not interpret bad channels, NaN values, or invalid source-network
   values.
7. Summarize the principal patterns instead of mechanically repeating every
   number.
8. Do not recalculate temporal differences. Use only the supplied
   **feature change values**.
9. The output must cover:
   - the main EEG characteristics of the early, middle, and last intervals;
   - the main changes from early to middle;
   - the main changes from middle to last;
   - whether the trajectory shows sustained increase, sustained decrease,
     reversal, or overall stability.
10. If changes are small or their directions differ across channels or brain
    regions, describe the signal as **overall stable** or showing **minor
    local changes**. Do not exaggerate.
11. Use terms equivalent to "increased," "decreased," "strengthened," or
    "weakened" only when multiple channels, ROIs, or source networks show a
    consistent direction.
12. Output exactly **one English paragraph of 120-180 English words**.
    Cover the most informative findings from per-channel band power, ROI-level
    band power, advanced frequency-domain features, anterior-posterior and
    left-right asymmetry, source-network features, and time-domain features.
    Do not force every feature family into the paragraph when its values are
    invalid or uninformative.
13. Do not output reasoning, a list, a heading, or JSON.

# Feature interpretation guide
## Band power
The summary contains **absolute power**, **relative power**, and
**0.5-45 Hz total power** for each EEG channel.
- **Absolute power** reflects the magnitude of power in each frequency band.
- **Relative power** is the proportion of a channel's 0.5-45 Hz total power
  contributed by each band.
- Use **relative power** when identifying the dominant frequency band.
- Use **absolute power** and **total power** mainly to describe overall signal
  strength.

Frequency-band definitions:
- **delta**: 0.5-4 Hz
- **theta**: 4-8 Hz
- **alpha**: 8-13 Hz
- **beta**: 13-30 Hz
- **gamma**: 30-45 Hz

## ROI relative band power
The ROI table summarizes relative band power in five scalp regions:
- **frontal**: FP1, FP2, F3, F4, F7, F8, FZ
- **central**: C3, C4, CZ
- **parietal**: P3, P4, PZ
- **occipital**: O1, O2, OZ
- **temporal**: T3, T4, T5, T6

Use ROI values to describe spatial distributions, such as whether a band is
concentrated in frontal, posterior, occipital, temporal, or central regions.
The summary also reports the **number of good channels** in each ROI. This is
a **data-quality indicator**, not a primary EEG feature. Avoid overinterpreting
an ROI when it contains few good channels.

## Advanced frequency-domain features
The summary contains these per-channel advanced spectral features:
- **spectral entropy**: how broadly spectral power is distributed across
  frequencies. Higher values indicate a more dispersed or complex spectrum;
  lower values indicate a more concentrated spectrum.
- **SEF Hz**: spectral edge frequency, the frequency below which most spectral
  power accumulates. A higher SEF generally indicates a greater high-frequency
  contribution.
- **aperiodic exponent**: the slope of the 1/f background spectrum. A larger
  value generally indicates a steeper decline in power with increasing
  frequency.
- **IAF Hz**: individual alpha frequency, the peak frequency within the alpha
  band.
- **alpha oscillatory power**: alpha-band oscillatory power after removing the
  1/f background.
- **theta/beta ratio**: relative strength of theta versus beta activity.
- **alpha/theta ratio**: relative strength of alpha versus theta activity.

Use these features to describe spectral concentration, alpha rhythmic
properties, broadband spectral shape, and the relationship between
low-frequency and high-frequency activity.

## Spatial asymmetry
### Left-right asymmetry
The summary contains spatial-asymmetry features for homologous left-right
channel pairs.
- **asymmetry log** is defined as `ln(P_right) - ln(P_left)`.
- **lateralization index** is defined as
  `(P_right - P_left) / (P_right + P_left)`.
- A positive value indicates relatively stronger right-sided power.
- A negative value indicates relatively stronger left-sided power.
- A value near zero indicates approximate left-right balance.

Use these values to describe clear left-right imbalances, with particular
attention to frontal alpha asymmetry measures such as **F3-F4 alpha**. Do not
interpret spatial asymmetry as an emotional or psychological state.

### Anterior-posterior asymmetry
The summary contains spatial-asymmetry features for homologous anterior and
posterior ROIs. Use them to describe anterior-posterior differences in
regional activity.

## Source-space network features
The source-network table summarizes relative band power in the Yeo-7
source-space networks:
- **Visual**
- **Somatomotor**
- **Dorsal Attention**
- **Salience / Ventral Attention**
- **Limbic**
- **Control / Frontoparietal**
- **Default Mode**

Describe source-network results only when `source-network available` is true
and the `number of epochs used` is sufficient. Interpret these estimates
**conservatively** because they are derived from EEG source localization.

## Time-domain features
The summary contains these per-channel time-domain features:
- **RMS**, **standard deviation**, **variance**, and **peak-to-peak amplitude**
  reflect signal magnitude and variability.
- **line length** reflects the total amount of temporal waveform variation.
- **zero-crossing rate** reflects how often the signal crosses zero.
- **Hjorth mobility** reflects the speed of frequency-related temporal change.
- **Hjorth complexity** reflects waveform complexity relative to a simple
  oscillatory pattern.

Use these features to describe signal magnitude, temporal variability, and
waveform complexity.
